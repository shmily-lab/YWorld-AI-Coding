# 手动标记为「已投」的公司，每行一个，会被自动从「可补投通道」剔除
#
# 用法：
#   1. 在工作台「可补投通道」页点卡片上的「✓ 已投」，可立即隐藏（存在本机浏览器）
#   2. 想长期生效 / 换设备也保留：点提示条上的「复制名单」，把公司名粘到本文件下面
#   3. 每次生成工作台（每天 09:35 / 21:00 自动跑）都会读本文件，把列出的公司自动剔除
#
# 写法：一行一个公司名，可用简称（如「蔚来」「亚信安全」），# 开头为注释
# 例：
# 蔚来
# 亚信安全

06 / SECURITY · 防火墙与 NAT

边界防火墙：最小权限策略 + 精细化 NAT

USG6500E 部署在园区网与校园网边界，trust 域对接 R4（172.16.12.0/24），untrust 域对接校园网（10.106.0.0/16）。安全策略默认全部拒绝、按需精确放行；NAT 采用 easy-ip，按网段精细授权出网。

NAT 出网策略（easy-ip）

放行　VLAN100/200 · 172.16.2.0/23 → 任意目的
放行　VLAN600 · 172.16.7.0/24 → 任意目的
限校园网　VLAN300/400 · 172.16.4.0/23 → 仅 10.0.0.0/8
禁出网　VLAN500 · 172.16.6.0/24 不配置 NAT 规则

安全策略（默认拒绝）

默认动作　拒绝全部（最小权限）
放行　172.16.0.0/16 → 校园网 10.0.0.0/8
放行　VLAN100/200/600 → Internet
放行　网管 172.16.2.0/24 → local（SSH）
放行　防火墙自身 ICMP 探测
出口默认路由：防火墙配置静态默认路由指向校园网网关 10.106.203.1，并通过 OSPF default-route-advertise always 向全网下发，内网设备无需各自配置静态默认路由。

09 / ACCEPTANCE · 验收测试矩阵

全量验收测试矩阵

按 核心→出口→汇聚→接入→服务→无线 顺序验证，覆盖 VLAN 隔离、出网权限、时间 ACL、管理平面与路由汇聚。以下为关键验收项。

连通性 · 隔离 · 出网权限

1PC2(VLAN100) ↔ PC3(VLAN200)：应不通（互访隔离）
2PC3 → 校园网 PC1：应通（可出网）
3PC4(300) ↔ PC5(400)：应通（互通）
4PC4 → 校园网：应通（仅限校园网）
5PC4 → Internet：应不通（禁 Internet）
6PC6(500) → PC2/PC4/PC7：应通（可达园区全网段）
7PC6 → 校园网：应不通（禁校园网/Internet）
8PC7(无线) → PC2：应通（内网可达）
9PC7(无线) → Internet：应通（可上 Internet）

时间 ACL · 管理平面 · 路由汇聚

10PC4 工作日 09–17 → WWW:80：拒绝（时间 ACL）
11PC4 工作日 → FTP:21：拒绝（时间 ACL）
12PC4 → Email:25/110：正常（不受限）
13PC6 工作日 → WWW/FTP：拒绝（时间 ACL）
14管理机 → 各设备 SSH：登录成功（管理平面）
15R4 → display ip routing-table：存在 3 条 /23 汇聚路由

真机化勘误对照表（课设 → 真机）

1课设时间范围不一致(09–20 / 11–17) → 统一 09:00–17:00 working-day
2R3 ACL 笔误 192.16.7.0 → 修正为 172.16.7.0
3WWW/FTP/Email 共用 172.16.2.2 → 拆分为 .10/.11/.12 三台独立服务器
4Eth-Trunk1 物理口未加入成员(聚合未生效) → 补全成员并启用 LACP
5SW2 stp priority 0 做根桥不合理 → SW4 根桥(4096)、SW2 备份(8192)
6防火墙 untrust→trust 全放行 → 默认拒绝 + 最小权限精确放行
7nat address-group 私转私无效 → 删除，统一 easy-ip 按 VLAN 授权
8R1/R4 默认路由指向 10.106.1.254(不直连校园网) → 改防火墙 OSPF 下发
9防火墙 OSPF 宣告 10.106.0.0/16(无权) → 仅宣告 172.16.12.0/24
10全局 dhcp enable 但无地址池 → R3 补全 VLAN600 全局 DHCP 池
11无统一管理平面(Telnet/明文/无对时) → 全网 SSH+AAA+NTP+SNMP Trap+TFTP

## 二、怎么用

```bash

## 三、学习闭环（这次新增的核心）

```
做题 → 答错自动进错题本 → 答对排入间隔复习（1/2/4/7/15/30/60 天）
            ↓
诊断：按知识点标签算掌握度 → 指出薄弱块 + 推荐重点练哪几题
            ↓
阶段全部通关 → 解锁对应融合题（必须综合前 N 阶段才能做出来）
```

### 1. 间隔复习（周期性巩固）
艾宾浩斯排期：答对则 interval 逐级拉长，答错退回 1 天后重做。
到期优先级：**错题未攻克 > ❗手动标记 > 间隔到期 > 融合题解锁**。
每天 21:00 的自动化任务会推送当日清单并写入 `复习清单/YYYY-MM-DD.md`。

### 2. 错题集
每次答错自动入册，记录错误原因、当时的 SQL、失败次数。重做通过后标记「已攻克」移出。
`python run.py wrong --do` 可以直接把错题本按顺序重做一遍。

### 3. 薄弱点诊断
63 道题都打了知识点标签（如 `反连接`、`窗口帧`、`索引失效`、`主子表顺序`）。
系统按标签统计掌握度：

| 情况 | 掌握度 |
|---|---|
| 一次做对 | 1.0 |
| 错了但后来做对 | 每多错一次扣 0.2（下限 0.4） |
| 始终没做对 | 0.3 起，每多错一次再扣 0.1 |

输出形如：

```
1. 【GROUP BY】薄弱（掌握度 30%）
   练了 1 道、错了 1 次，正确率明显偏低，是当前的短板
   重点练：S2-Q02、S2-Q03、S2-Q04
```

### 4. 标记笔与笔记
- 网页端在题面里**选中任意一段文字** → 浮出「✎ 标记这段」→ 写批注，之后以黄色高亮常驻
- 每题可写笔记（自动保存）、打标记：⭐收藏 / ❗易错（立刻进复习队列）/ ✓已掌握
- `python run.py notes -o notes.md` 导出成 Markdown

### 5. 分层解题思路
「💡 看思路」一次只展开一步，共 3~4 步，**每步只说下一个动作、不剧透最终 SQL**，
最后一步教你怎么验证结果。命令行是 `python run.py step <题号>`。

### 6. 融合复习题（独立完成的综合题）
阶段 10 的 6 道题默认 🔒 锁定，前置阶段全部通关才解锁：

| 题号 | 综合了 | 考点 |
|---|---|---|
| S10-Q01 | 1+2 | NULL 统计、条件聚合、一行多口径 |
| S10-Q02 | 2+3 | LEFT JOIN、去重计数、GROUP BY 表达式 |
| S10-Q03 | 3+4+5 | 反连接计数、标量子查询、CTE、窗口占比 |
| S10-Q04 | 4+5 | 三层 CTE、RANK、CASE 分层 |
| S10-Q05 | 6 | 归档表结构、主子表删除顺序、交付自检 |
| S10-Q06 | 8+9 | 联合索引方向、避免临时排序、覆盖索引 |

## 四、判分机制

| 模式 | 用于 | 判据 |
|---|---|---|
| `exact` | 查询题 | 排序后的行多重集比对；数值容差 `max(0.005, |a|×1e-9)` |
| `check` | DML/DDL | 校验 SQL 返回 `PASS`/`1`；**可访问 `base.*` 原始基准库做逐行比对** |
| `plan` | 索引题 | 对最后一条 SELECT 的 EXPLAIN 做子串断言 |

隔离三层：练笔用会话副本、判分用全新临时副本、题库基准只读。

## 六、固化的 Skill

```
SKILL.md                        触发条件 + 五步工作流 + 避坑清单
references/workbench-guide.md   架构、判分机制、出题规范、踩坑、学习闭环实现细节
